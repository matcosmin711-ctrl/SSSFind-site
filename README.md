# SSSFind — Public website

SSSFind is a search and price-comparison assistant operated by CCM Digital Systems in Germany.

- Website source: `index.html`.
- Application backend: the separate, private SSSFind app repository.
- Public legal links: `https://sssfind-api-production.up.railway.app/legal/` endpoints.
- The website is an informational landing page; it is not the mobile app or the backend API.
- Deployment and any custom domain must be verified separately before publicly advertising this website.

Never commit store credentials, personal information or API secrets here.
